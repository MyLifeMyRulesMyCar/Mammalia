# MAMMALIA — Build Your Own Hardware

An interactive product configurator for the MAMMALIA carrier-board platform.
One core carrier in the middle, three interchangeable compute modules ("brains"),
and four swappable secondary PCBs ("HATs") — each mapping to a real end product.

## How it works

1. **Choose your brain** — Radxa CM3 / Orange Pi CM4 / Luckfox Core3566
2. **Carrier** — fixed, always in the build (MAMMALIA Core Carrier)
3. **Secondary PCB** — pick one HAT: Delphinidae (Edge Controller), Mustelidae (HMI),
   Castoridae (Router), Sciuridae (NAS). Picking a HAT is what decides the end product.
4. **Customize** — shell finish, mounting style, and add-ons, with a live power-budget
   meter (à la a game loadout screen)
5. **Manufacture** — press the button to watch a short assembly animation, then get
   your finished product card with an exportable build sheet (JSON)

A silver trace line animates across the selected brain → carrier → HAT → product
every time a choice changes. Unselected options dim automatically, and the ▲▼
buttons on each column cycle through options for a faster pick.

Everything — every board and product illustration — is inline SVG generated by
the page itself, so the file has **zero external asset dependencies** beyond two
Google Fonts (Space Grotesk, JetBrains Mono) loaded over the network. It runs
entirely client-side.

## Files

- `index.html` — the whole app (HTML + CSS + JS in one file)

## Running it

Just open `index.html` in any modern browser — no build step, no server required.
To host it, drop it on any static host (GitHub Pages, Netlify, S3, etc.) as-is.

## Customizing the data

All product data lives in two arrays near the top of the `<script>` block:

- `BRAINS` — compute modules (id, name, color, wattage, tagline, spec chips)
- `HATS` — secondary PCBs (id, name, kind, color, wattage, tagline, spec chips,
  add-ons with their wattage, and the `product` copy shown on reveal)

Change names, wattages, colors, or copy there and the whole UI (cards, SVGs,
power-budget math) updates automatically.

Note: the power-budget meter is an illustrative game-style mechanic for this
showcase page, not a substitute for a real engineering power budget.
